# WP3 Data Directory

This folder stores data artifacts for **TrustGenAI WP3 (Robust GenAI for multi-modal data)**.

## Purpose

The WP3 data track supports:
- multi-modal dataset curation
- demonstrator use-case definition
- model integration and evaluation workflows

## Data Types in Scope

WP3 targets industrial datasets that may combine:
- text
- images
- audio
- sensor streams / time-aligned machine context

## Expected Contents

Use this directory for WP3-relevant data artifacts such as:
- curated datasets (or pointers to controlled storage)
- annotation files and schemas
- modality alignment/mapping files
- train/validation/test split definitions
- use-case specification files linked to Deliverable D3.1

## Data Quality and Interoperability

For consistency with WP3 Task 3.1, data preparation should emphasize:
- cleaning and quality checks
- annotation quality
- cross-modality alignment and interoperable formats

## Sharing and Privacy

When sharing data externally, company-origin data should be:
- anonymized and/or modified as needed
- reviewed for confidentiality before publication

## Traceability

Each dataset release should include minimal metadata:
- source context
- modalities included
- preprocessing/annotation steps
- intended use case
- known limitations

This helps connect data assets to WP3 deliverables (**D3.1**, **D3.2**, **D3.3**) and to downstream demonstrator results.
