# TrustGenAI
TrustGenAI is a collection of starter kits, tools, and practical resources for building **trustworthy Generative AI applications** in industrial and professional environments. The repository brings together reusable examples and implementation guidance developed within the TrustGenAI project.
 
## Purpose
Generative AI is rapidly moving from experimentation to real-world applications. However, successful adoption requires more than good model performance. Trustworthy AI systems must also address aspects such as reliability, transparency, robustness, and risk management.
 
This repository provides hands-on starter kits that help developers and innovators apply trustworthiness principles when designing and deploying GenAI solutions.
 
## Repository Structure
This repository contains multiple starter kits, each focusing on a specific aspect of trustworthy GenAI.
- **Timeseries starter kit**: See './Timeseries starter kit' for documentation and usage instructions.
- **Multimodal starter kit**: See './Multimodal starter kit' for documentation and usage instructions.
 Each starter kit contains its own detailed README with setup instructions, requirements, and examples.

Additionally, this github also contains a 'Trustworthiness Playbook', a reference document that can guide you through developing more trustworthy AI applications. The principles described in this playbook have been applied to both starter kits.
 
## Getting Started
1. Clone this repository.
2. Navigate to the starter kit you want to explore.
3. Follow the instructions in the corresponding README.
 
```bash
git clone https://github.com/sirris-be/trustgenai.git
cd trustgenai
```
